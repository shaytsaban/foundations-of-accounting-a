# יסודות החשבונאות א׳

אתר הקורס. דף השער הוא `index.html`.

- `materials/exercise-booklet.pdf`: חוברת התרגילים של הקורס
- `materials/detailed-solutions.pdf`: חוברת הפתרונות המפורטים
- `lectures/lecture-1/presentation.html`: מצגת שיעור 1
- `lectures/lecture-1/summary.pdf`: סיכום מורחב של שיעור 1
- `lectures/lecture-2/presentation.html`: מצגת אינטראקטיבית של שיעור 2 (מיון ובנייה של הדוחות, ו-22 שאלות תרגול)
- `lectures/lecture-2/summary.pdf`: סיכום מורחב של שיעור 2
- `lectures/lecture-3/presentation.html`: מצגת אינטראקטיבית של שיעור 3 (עלות המכירות ורווח גולמי, השאלה המרכזית, חילוץ עודפים, ו-22 שאלות תרגול)
- `lectures/lecture-3/summary.pdf`: סיכום מורחב של שיעור 3
- `assets/`: גופנים ותמונת המרצה (`shay.jpg`)
